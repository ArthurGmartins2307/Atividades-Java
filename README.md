# ☕ Exercícios Java — Fundamentos e Prática

Repositório dedicado ao meu aprendizado de **Java**, com exercícios práticos desenvolvidos para consolidar os fundamentos da linguagem, compreender a programação orientada a objetos e desenvolver raciocínio lógico para a construção de sistemas.

## 🎯 Objetivos

- Construir uma base sólida em Java.
- Desenvolver raciocínio lógico e capacidade de resolver problemas.
- Compreender a programação orientada a objetos (POO).
- Aprender a estruturar classes e distribuir responsabilidades.
- Trabalhar com arrays e coleções de objetos.
- Entender como diferentes objetos se relacionam dentro de um sistema.
- Preparar a base necessária para desenvolver aplicações backend e projetos mais complexos.

## 📚 Conteúdos estudados e praticados

### 1. Fundamentos da linguagem

- Declaração e utilização de variáveis.
- Tipos de dados, incluindo `String`, `int`, `double` e `boolean`.
- Operadores de atribuição e comparação.
- Estruturas condicionais com `if` e `else`.
- Laços de repetição com `for`.
- Métodos, parâmetros e chamadas de métodos.
- Diferenças entre atributos de instância e atributos estáticos (`static`).

### 2. Programação orientada a objetos (POO)

- Criação e instanciação de classes.
- Construção de objetos com `new`.
- Atributos e métodos.
- Construtores e inicialização de objetos.
- Uso de `this` para referenciar o próprio objeto.
- Diferenças entre atributos de instância e atributos compartilhados por meio de `static`.
- Encapsulamento conceitual de informações e responsabilidades.
- Interação entre objetos por meio de atributos e métodos.

### 3. Relacionamento entre objetos

Pratiquei a criação de classes que possuem referências a objetos de outras classes, entendendo como os dados podem se relacionar dentro de uma aplicação.

Exemplos desenvolvidos durante os exercícios:

- **Biblioteca:** relacionamento entre livros, usuários e biblioteca.
- **Pedidos e clientes:** associação de pedidos aos respectivos clientes.
- **Contas bancárias:** operações de depósito, saque e transferência entre contas.
- **Carros e motores:** relacionamento entre um carro e seu motor.
- **Disciplinas e professores:** associação de uma disciplina a um professor.
- **Pessoas e cachorros:** relacionamento entre um animal e seu dono.

Esses exercícios ajudaram a compreender como os objetos podem representar entidades de um sistema e colaborar para realizar operações.

### 4. Arrays e arrays de objetos

Uma das partes centrais dos estudos foi compreender a sintaxe, o funcionamento e a utilização de arrays em Java.

- Declaração e inicialização de arrays.
- Acesso aos elementos por meio de índices.
- Compreensão de que os índices começam em `0`.
- Uso de `length` para consultar a capacidade de um array.
- Percurso de arrays com laços `for`.
- Armazenamento de objetos em arrays.
- Criação de arrays de objetos utilizando inicialização direta.
- Cadastro e listagem de objetos.
- Controle da quantidade de elementos cadastrados.
- Diferença entre capacidade máxima e quantidade efetivamente utilizada.
- Acesso a atributos e métodos de objetos armazenados em arrays.
- Compreensão inicial de referências não inicializadas (`null`).

### 5. Métodos, validações e regras de negócio

Os exercícios também envolveram a implementação de comportamentos e validações, aproximando os estudos de situações práticas.

Entre os exemplos:

- Impedir depósitos com valores inválidos.
- Verificar saldo antes de realizar operações financeiras.
- Implementar transferências entre contas.
- Controlar o estado de empréstimo e devolução de livros.
- Contabilizar objetos ou registros criados.
- Cadastrar e listar elementos respeitando a capacidade disponível.

## 🧠 Como estou estudando

Minha abordagem é baseada na prática progressiva. Primeiro, trabalho os conceitos individualmente; depois, combino esses conceitos em exercícios que exigem mais raciocínio e organização.

Também revisito erros de implementação para entender suas causas, em vez de apenas substituir o código por uma solução pronta.

O objetivo é desenvolver autonomia para analisar problemas, estruturar soluções e escrever código com mais clareza.
